# Roadmap

Stackglass 1.1 ships GlassLens and connects CLI, MCP, dashboard, and watch. Later work deepens adapters and coverage providers rather than adding unbounded MCP tools.

| Release | Focus                                                      | Status         |
| ------- | ---------------------------------------------------------- | -------------- |
| 0.1     | Core + CLI                                                 | Shipped in 1.0 |
| 0.2     | GlassIndex + Timeline                                      | Shipped in 1.0 |
| 0.3     | GlassLab                                                   | Shipped in 1.0 |
| 0.4     | MCP                                                        | Shipped in 1.0 |
| 0.5     | Debugging + Failure Center                                 | Shipped in 1.0 |
| 0.6     | Coverage + Contracts                                       | Shipped in 1.0 |
| 0.7     | Mutation + Flake Detection                                 | Shipped in 1.0 |
| 0.8     | Plugin UI (`glass dashboard`)                              | Shipped in 1.0 |
| 0.9     | Adapter SDK                                                | Shipped in 1.0 |
| 1.0     | Stable                                                     | Shipped        |
| 1.1     | GlassLens, live dashboard, watch autoRun, failure classes  | Current        |
| 1.2     | Additional language adapters and richer coverage providers | Planned        |
| 1.3     | Optional remote collaboration (explicit opt-in only)       | Planned        |

New MCP capabilities should land as arguments/modes of the existing 22 tools unless a new canonical tool is conceptually justified.
